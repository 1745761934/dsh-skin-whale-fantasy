## 六、风险与注意事项

1. **宿主版本对不上**：社区版最高验证宿主为 `0.2.2-rc.3`，本机 `Info.plist` 读出 `0.13.0`（非官方版本号体系）。装完先跑 `purge-community status` + `selfcheck`，标"未验证"就先 `diagnose` 看锚点漂移，不要直接点应用。
2. **重启是必须的**：补丁只有重启后才被加载，当前进程不热重载这些模块。社区版明说"不自动应用、不自动重启"。
3. **两个 profile 分开装**：`web` 与 `desktop` 各自独立，不能只装一个。
4. **网络范围限制**：社区版 README 声明开源版只认本地靶场 IP（回环 + RFC1918），域名先按系统解析，混有公网地址一律拦。
5. **原版不许倒卖**，二开必须署名 `YuJunZhiXue/dsh-purge`。
